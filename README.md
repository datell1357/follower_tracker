# 팔로워 트래커

여러 SNS의 팔로워 수와 변화를 휴대폰에 기록하고 홈 화면 위젯에서 확인하는 무료 모바일 앱을 개발한다. 사용자가 앱 내부에서 로그인한 SNS 세션으로 데이터를 읽고 기기에 보관한다. 전체 명단을 검증할 수 있는 SNS에서는 언팔로우 추정과 맞팔 상태를 제공한다.

Android·iOS 네이티브 앱과 위젯을 구현 중이다. SNS별 세션 수집과 실제 기기 위젯 동작의 검증 상태는 구현 기록에 남긴다.

Android에서는 Instagram을 연결한 뒤 **설정 → 1분 빠른 추적 → 빠른 추적 시작**으로 짧은 간격의 수집을 실행할 수 있다. 기존 로그인 세션으로 공식 본인 프로필의 정확한 수를 새로 읽고, 저장 직후 홈 화면 위젯 갱신을 요청한다. 실행 중 알림이 표시되고 한 번에 최대 약 6시간 실행한다. 일반 예약에는 15분 이상 간격을 선택할 수 있다.

API 36 에뮬레이터에서 앱 화면을 닫은 채 약 7분 동안 8회 연속 수집과 실제 위젯 반영을 확인했다. SNS 요청 제한·잠금·절전·실기기 조건과 24시간 연속 1분 수집을 보장하는 결과는 아니다. 다른 SNS와 iOS의 빠른 추적은 미검증이다. [실제 시험 범위](docs/DEVICE_VALIDATION.md)
