# 팔로워 트래커

여러 SNS의 팔로워 수와 변화를 휴대폰에 기록하고 홈 화면 위젯에서 확인하는 무료 모바일 앱을 계획한다. 사용자가 앱 내부에서 로그인한 SNS 세션으로 데이터를 읽고 기기에 보관하는 구조를 목표로 한다. 전체 명단을 검증할 수 있는 SNS에서는 언팔로우 추정과 맞팔 상태를 제공한다.

Android·iOS 네이티브 앱과 위젯을 구현 중이다. SNS별 세션 수집과 실제 기기 위젯 동작의 검증 상태는 구현 기록에 남긴다.

- [구현 가능성 조사](docs/FEASIBILITY.md): 쿠키 기반 접근, SNS별 조건, 위젯 제약, 경쟁 앱, 배포 판단
- [구현 계획서](docs/IMPLEMENTATION_PLAN.md): 단계별 범위, 로컬 구조, 세션·명단 처리, 실기기 완료 조건
- [구현 기록](docs/WORK_LOG.md): 단계별 진행 상태와 실제 검증 증거
- [개발과 검증](docs/DEVELOPMENT.md): 개발 환경, 핵심 테스트, 수집 경로의 검증 범위
