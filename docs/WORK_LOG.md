## 2026-10-01

- 작업 시작 시 `datell1357/follower_tracker`는 빈 저장소였다. 기본 브랜치는 `main`이다.
- Xcode 26.6, Android SDK 36, JDK 21을 확인했다. 연결된 Android 기기는 없고 iOS 시뮬레이터는 모두 종료 상태다.
- 실기기 종류·테스트 SNS와 iOS 시뮬레이터 실행에 관한 백그라운드 질문을 남겼다. 비밀번호·쿠키를 채팅으로 요청하지 않는다.
- 원래 계획의 Android/Compose, iOS/SwiftUI 및 네이티브 세션·위젯 구성을 적용한다.
- `797d00c` 조사·구현 기준 커밋을 origin/main에 푸시했다.
- Kotlin 핵심 13개, Swift 핵심 12개, WebView 공통 캡처 5개 테스트가 통과했다. 누락을 0명으로 처리하지 않고, 부분 명단·커서 반복·다른 계정·공개 프로필을 완전한 자기 명단으로 처리하지 않는 조건을 검사했다.
- 첫 Android 검사는 컴파일러 캐시 권한과 한글 경로의 대체 실행 문제로 실패했다. 프로세스 내 컴파일 설정 후 같은 검사를 다시 실행해 통과했다. Swift는 컴파일러 표준 모듈 캐시에 대한 권한을 승인받아 실행했다.
- `fce2ad3` 핵심 모델·분석·응답 처리와 `0a7000a` Windows wrapper 줄바꿈 정규화를 푸시했다. 두 커밋의 Core checks CI가 통과했다.
- Android 앱·위젯은 한 차례 debug 빌드와 lint가 통과했다. 합성 HTTP 응답으로 허용 호스트·인증 만료·403·429·리다이렉트·응답 크기 검사 7개가 통과했다. 이후 추가한 세션 갱신 경계와 실제 Android 저장·화면 테스트는 검증 중이다.
- iOS 쿠키 도메인·호스트 전용 범위·경로 경계·HTTPS·만료·저장 복원 검사를 추가했고 Swift 핵심 17개가 통과했다. 앱·위젯 빌드는 별도로 진행 중이다.
- Pixel API 36을 읽기 전용 및 스냅샷 저장 없이 부팅하고 debug 앱 설치를 확인했다. 연결된 사용자 실기기와 SNS 로그인은 아직 없다.
- `f1fdc53` iOS 쿠키 도메인·경로·HTTPS·만료·복원 검사를 푸시했고 해당 커밋의 핵심 CI가 통과했다.
- iOS 앱과 위젯 확장의 Debug 시뮬레이터 빌드 및 Release 기기용 빌드가 서명 없이 통과했다. 프로젝트 재생성의 동일성, plist·entitlements·개인정보 manifest·아이콘 메타데이터를 검사했고 앱·위젯에 manifest가 포함됨을 확인했다. App Group DB·Keychain 공유와 동시 수집 임대 잠금, 위젯의 대시보드 링크를 구현했다. 시뮬레이터 실행·화면 검사는 질문 응답 대기 중이며, 빌드 성공을 실제 공유 저장소 성공으로 해석하지 않는다.
- `5138030` iOS 앱·위젯 구현을 푸시했고 해당 커밋의 Native checks CI에서 핵심 검사·프로젝트 재생성·iOS Release 빌드가 통과했다.
- iOS 앱과 위젯의 세션 저장·응답 쿠키 반영·삭제에 같은 파일 잠금을 적용했다. macOS의 별도 프로세스가 잠금 중 진입할 수 없고 오류 후 잠금이 풀리는 검사 2개를 추가해 Swift 핵심 19개가 통과했다. 실제 iOS Keychain 공유 검증은 별도 대기 상태다.
- 연결 해제 후 같은 계정을 재연결한 경우, 이전 요청의 수치·상태·명단이 새 연결에 저장되지 않도록 iOS 저장소와 수집기에 연결 시점 검사를 적용했다. 계정 선택 후 늦게 도착한 다른 계정의 관계 결과도 화면에 반영하지 않는다. 변경 후 앱·위젯의 Debug 및 Release 빌드가 모두 통과했다.

아직 실제 SNS 세션·백그라운드 갱신을 검증하지 않았다. 빌드 성공과 목 응답 테스트는 실제 데이터 수집 성공으로 취급하지 않는다.
