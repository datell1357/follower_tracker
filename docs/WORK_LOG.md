- 작업 시작 시 `datell1357/follower_tracker`는 빈 저장소였다. 기본 브랜치는 `main`이다.

- `0671aa0` Android 앱·위젯 구현을 푸시했다. Android CI 범위를 핵심 검사에서 앱·테스트 APK·단위 검사·debug/release lint·Release 빌드까지 확장했다. 로컬 에뮬레이터 런타임 검사와 원격 빌드 CI는 구분한다.

- 계획서의 `RelationshipChange` 요구에 맞춰 두 플랫폼에 영구 이탈 추정 기록을 추가했다. 최신 명단 세 번만 비교해 과거 후보가 사라지던 한계를 해결하고, 최초 근거 명단·관측 시각·미관측 횟수·마지막 확인을 암호화해 보존한다. `처음 미관측`·`연속 미관측`·`다시 관측됨`을 표시하며 재등장 후 새 이탈은 별도 기록으로 남긴다. 원인을 실제 언팔로우로 확정하지 않는다.

- `9547b0d` 영구 이탈 추정 기록을 푸시했고 동일 SHA의 [Native checks CI](https://github.com/datell1357/follower_tracker/actions/runs/36809780249)가 통과했다.
