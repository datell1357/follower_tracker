# 구현 기록

목표: IMPLEMENTATION_PLAN.md에 따라 Android·iOS 앱과 홈 화면 위젯을 구현하고 실제 SNS 로그인 세션 수집을 검증한다. 모든 제품 기능은 무료이며 세션과 관계 명단은 기기 안에서 처리한다.

## 단계와 완료 증거

| 단계 | 상태 | 완료에 필요한 증거 |
| --- | --- | --- |
| 저장소 기준 문서와 개발 환경 | 진행 중 | 계획·조사 문서 보존, 원격 저장소 일치, 단계별 커밋·푸시 |
| 데이터 모델·관계 분석·응답 처리 | 대기 | 두 플랫폼 테스트: 첫 스캔, 부분 실패, ID 변경·계정 전환, 페이지 종료, 오류 보존 |
| Android 앱·세션·저장·예약 수집 | 대기 | 빌드·테스트·lint, 실제 로그인 및 WebView 종료 후 재수집 |
| Android 위젯·화면 검증 | 대기 | 작은/중간 위젯, 빈/성공/오류 상태, 화면·주요 상호작용 증거 |
| iOS 앱·세션·저장·수집 | 대기 | 앱·확장 빌드, 핵심 테스트, 실제 로그인과 네이티브 요청 |
| iOS 위젯·화면 검증 | 대기 | App Group·Keychain 공유, 실제 위젯 갱신·잠금 상태 결과 |

| 배포 준비 | 대기 | 실제 데이터 처리와 일치하는 개인정보 설명, 수집 허용 범위와 서명 설정 |

## 2026-10-01

- 원격 저장소는 `datell1357/follower_tracker`, 기본 브랜치는 `main`이며 원격 커밋은 없다.
- Xcode 26.6, Android SDK 36, JDK 21을 확인했다. 연결된 Android 기기는 없고 iOS 시뮬레이터는 모두 종료 상태다.
- 실기기 종류·테스트 SNS와 iOS 시뮬레이터 실행에 관한 백그라운드 질문을 남겼다. 비밀번호·쿠키를 채팅으로 요청하지 않는다.
- 원래 계획의 Android/Compose, iOS/SwiftUI 및 네이티브 세션·위젯 구성을 적용한다.

아직 실제 SNS 세션·백그라운드 갱신을 검증하지 않았다. 빌드 성공과 목 응답 테스트는 실제 데이터 수집 성공으로 취급하지 않는다.
