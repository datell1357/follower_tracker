# 기기·SNS 검증 기록

빌드와 합성 데이터 검사는 완료된 범위만 [구현 기록](WORK_LOG.md)에 기록한다. 아래 실제 세션 검사는 아직 실행하지 않았다. 실제 수집 성공 전에는 구현된 후보 경로를 지원 확정으로 표시하지 않는다.

## 현재 수집기 범위

| SNS | 구현한 수 수집 경로 | 전체 명단 경로 | WebView 종료 후 수집 | Android 실제 SNS | iOS 실제 SNS |
| --- | --- | --- | --- | --- | --- |
| Instagram | 자기 ID 확인 후 세션 기반 User Info 요청 | 페이지 커서·계정·시작/종료 수 검사 | 네이티브 요청 후보 | 미검증 | 미검증 |
| TikTok | 로그인 문맥과 일치하는 자기 프로필 JSON | 구현된 전체 명단 경로 없음 | 자기 프로필 요청 후보, 실패 시 상태 표시 | 미검증 | 미검증 |
| X | 자기 ID와 일치하는 WebView 프로필 정보 | 구현된 전체 명단 경로 없음 | 현재 전경 수집만 구현 | 미검증 | 미검증 |
| Facebook | 자기 ID와 일치하는 WebView 팔로워 정보 | 구현된 전체 명단 경로 없음 | 현재 전경 수집만 구현 | 미검증 | 미검증 |
| Reddit | 세션으로 자기 프로필 구독자 수 요청 | 구현된 전체 명단 경로 없음 | 네이티브 요청 후보 | 미검증 | 미검증 |

Facebook 개인 프로필·프로페셔널 모드·페이지의 지원을 하나의 결과로 묶지 않는다. X·Facebook 전경 경로는 사용자가 프로필을 열어 읽은 값을 위젯에 표시하는 구현이며, 앱을 열지 않아도 새 값을 수집하는 요구의 검증 성공을 뜻하지 않는다.

## Android 홈 화면 확인 — 2026-10-01

별도 Medium Phone 에뮬레이터(Android 16, API 36, Google APIs, 1080×2400, 420 dpi)에 Debug 앱을 설치하고 실제 런처에서 위젯을 검사했다. 기존 Pixel 에뮬레이터와 로그인 대기 중인 iOS 시뮬레이터의 데이터는 보존했다.

| 검사 | 결과 | 확인 범위 |
| --- | --- | --- |
| 앱의 모든 계정 위젯 추가 버튼 | 통과 | 실제 런처 확인창에 빈 상태 미리보기 표시 |
| 확인창 취소와 재요청 | 통과 | 취소 뒤 설치된 위젯 0개, 다시 요청해 홈 화면에 추가 가능 |
| 홈 화면 빈 상태 | 통과 | 이 런처의 2×3 배치에서 SNS 연결하기가 한 줄로 표시됨 |
| 기존 위젯의 로딩 안내 회복 | 통과 | 앱 복귀 후 기존·신규 두 위젯 모두 정상 빈 상태와 RemoteViews 표시 |
| 위젯 누르기와 설정 탭 이후 재진입 | 통과 | 홈 화면 위젯에서 앱 열림, 기존 설정 탭 대신 추적 탭 선택 |
| 실제 수치·증감·계정 선택·자동 수집 | 미실행 | 실제 로그인과 기록 없음 |
| 다른 런처·크기 조절·실기기 잠금과 절전 | 미실행 | 별도 기기 검사 필요 |

앱 복귀 시 위젯을 다시 그리는 작업은 기기에 저장된 기록만 읽으며 SNS에 새 수집 요청을 보내지 않는다. 2×2 크기 힌트가 있어도 시험 런처의 실제 배치는 2×3이었다. 크기 힌트만으로 원하는 셀 배치나 다른 런처 지원을 확인했다고 기록하지 않는다.

최종 Debug·테스트 APK 및 Release(R8) 빌드, HTTP 단위 검사 7개, debug/release lint가 통과했다. lint는 오류 0개와 기존 UseKtx 제안 3개다. 같은 기기에서 앱 화면·작업 취소·Intent 반복 전달 5개와 위젯 RemoteViews 6개, 총 11개 런타임 검사가 통과했다. Intent 검사와 별도로 실제 홈 화면 클릭 결과를 확인했다. 최종 Debug APK SHA-256은 `1285413302946e4a5de0da3c8c4e1c248abd543d270a60c0f0d1d88b96bebabc`다. 합성 위젯 수치를 앱 DB에 저장하지 않았다.

첫 APK 갱신 때 Glance의 패키지 갱신 Receiver 시작 중 앱 ANR이 발생했고, Cold Boot 때 System UI와 Google Play services의 ANR도 발생했다. 이후 빌드·설치·검사를 순서대로 실행했지만 초기 실패의 원인이 앱 코드에서 해결됐다고 판정하지 않는다. 관련 로그와 화면을 로컬에 보존했으며, 이번 결과를 안정적인 기기 재시작이나 실기기 백그라운드 수집의 증거로 사용하지 않는다.

## iOS 홈 화면 확인 — 2026-10-01

`b61a161bb05e4c299eabcd8089d80a3478345ed5` 소스를 별도 iPhone 17 시뮬레이터(iOS 26.5)에 ad hoc 서명으로 빌드·설치하고 실제 iOS 위젯 갤러리와 홈 화면을 조작했다. 직접 로그인 대기 중인 iPhone 17 Pro의 화면과 데이터는 유지했다.

| 검사 | 결과 | 확인 범위 |
| --- | --- | --- |
| 작은·중간·큰 갤러리 미리보기 | 통과 | 세 크기 모두 계정 연결 전 안내 표시 |
| 작은·중간·큰 홈 화면 추가 | 통과 | 실제 홈 화면의 빈 상태가 잘림 없이 표시됨 |
| 중간·큰 위젯 누르기 | 통과 | 앱의 추적 화면 열림 |
| 설정 탭에서 홈으로 나온 뒤 큰 위젯 누르기 | 통과 | 기존 설정 탭 대신 추적 탭이 선택됨 |
| 실제 SNS 값·증감과 표시 계정 선택 | 미실행 | 로그인한 계정과 수치 기록 없음 |
| 세션의 Keychain 공유·백그라운드 수집·위젯 갱신 | 미실행 | 실제 로그인과 기기 검증 필요 |

시험 시 공유 DB의 계정·수치·명단·이탈 기록은 모두 0건이었다. 합성 수치를 앱 DB에 저장하지 않았으며 화면 자료는 로컬에 보존했다. 빈 상태가 표시된 결과만으로 암호화 기록 읽기나 실제 세션의 공유가 성공했다고 판정하지 않는다. 이 결과는 시뮬레이터 화면 검사이며 실기기의 잠금·절전·예약 실행 결과는 포함하지 않는다.

## 로그인에서 위젯까지

본인 계정의 로그인은 앱 안의 공식 SNS 페이지에서 사용자가 직접 진행한다. 비밀번호·쿠키·원시 명단은 채팅이나 저장소에 전달하지 않는다. 실기기 종류와 시험할 SNS가 정해지면 아래 순서로 결과를 기록한다.

1. OS·앱·WebView 버전, SNS 계정 유형과 익명 시험 식별자를 기록한다.
2. 공식 화면에서 자기 계정을 확인한 뒤 앱의 연결 확인을 실행한다. 정확한 수·수집 시각을 같은 시점의 공식 화면과 비교한다. 축약 수를 정확한 정수로 바꾸어 기록하지 않는다.
3. 연결 창을 닫고 앱에서 수 수집을 다시 실행한다. 다른 프로필, 로그인 만료, 확인 화면, 응답 변경이 마지막 정상 기록을 덮어쓰지 않는지도 확인한다.
4. 작은·중간·큰 홈 화면 위젯을 추가하고 표시 계정을 선택한다. 앱의 저장값·시각·상태와 비교하고 위젯을 눌러 앱이 열리는지 확인한다.
5. 앱을 열지 않은 상태에서 실제 새 수치가 관측되는지 확인한다. 예약 요청 시각, 실제 요청 시각, 위젯 표시 시각을 구분한다. 전경 수집 경로는 전경 전용으로 기록한다.
6. 앱 재실행·기기 재시작·화면 잠금·네트워크 단절과 복구·절전 상태를 검사한다. iOS에서는 서명된 앱·위젯의 App Group·Keychain 공유도 확인한다.
7. 대상 SNS 연결을 해제하고 그 SNS의 세션·기록만 제거되는지, 다른 SNS와 늦게 완료되는 요청에 영향이 없는지 확인한다.

## 관계 명단

Instagram 후보 경로에서 한 페이지를 넘는 명단을 읽고 정상 커서 종료·중복 제거·계정 일치·필터링 여부를 확인한다. 시작과 종료의 수가 같아도 동시점 스냅샷임을 증명하지는 않으므로 비원자적 수집으로 기록한다.

참여자가 동의한 시험 계정의 수동 관계 변경으로 맞팔의 두 방향, 첫 스캔 기준 생성, 이탈 후보, 다음 정상 스캔에서의 연속 미관측을 확인한다. 앱이 계정 삭제·비활성화와 실제 언팔로우 원인을 구분했다고 보고하지 않는다. 중간 페이지 실패와 취소 뒤에는 이전 완료 명단이 유지돼야 한다.

## 관찰 결과 양식

```text
시험 ID / OS / 앱 버전 / SNS / 계정 유형:
시험 시각 / 공식 화면 비교 시각:
로그인 및 자기 ID 확인:
정확한 수 수집과 정밀도:
WebView 종료 뒤 요청 결과 및 오류 종류:
전체 명단 페이지 수 / 종료 근거 / 불완전성:
작은·중간·큰 위젯 / 표시 계정 / 앱 열기:
예약 요청 / 실제 수집 / 위젯 갱신 시각:
잠금 / 재시작 / 단절 복구 / 절전:
연결 해제 후 세션·기록·다른 SNS 보존:
24시간 관찰 / 출시 후보 72시간 관찰:
확정할 기능 / 전경 전용 기능 / 실패·미검증 기능:
```

현재 실제 SNS 시험, 24시간 및 72시간 관찰 결과는 없다. 기간이 경과했다는 사실을 관찰 성공으로 대신 기록하지 않는다.
