# 기기·SNS 검증 기록

빌드와 합성 데이터 검사는 완료된 범위만 [구현 기록](WORK_LOG.md)에 기록한다. 아래 실제 세션 검사는 아직 실행하지 않았다. 실제 수집 성공 전에는 구현된 후보 경로를 지원 확정으로 표시하지 않는다.

## 현재 수집기 범위

| SNS | 구현한 수 수집 경로 | 전체 명단 경로 | WebView 종료 후 수집 | Android 실제 SNS | iOS 실제 SNS |
| --- | --- | --- | --- | --- | --- |
| Instagram | 자기 ID 확인 후 세션 기반 User Info 요청 | 페이지 커서·계정·시작/종료 수 검사 | 네이티브 요청 후보 | 미검증 | 미검증 |
| TikTok | 로그인 문맥과 일치하는 자기 프로필 JSON | 구현된 전체 명단 경로 없음 | 자기 프로필 요청 후보, 실패 시 상태 표시 | 미검증 | 미검증 |
| X | 자기 ID와 일치하는 WebView 프로필 정보 | 구현된 전체 명단 경로 없음 | 현재 전경 수집만 구현 | 미검증 | 미검증 |
| Facebook | 자기 ID와 일치하는 WebView 팔로워 정보 | 구현된 전체 명단 경로 없음 | 현재 전경 수집만 구현 | 미검증 | 미검증 |
| Reddit | 세션으로 자기 프로필 구독자 수 요청 | 구현된 전체 명단 경로 없음 | 네이티브 요청 후보 | 미검증 | 미검증 |

Facebook 개인 프로필·프로페셔널 모드·페이지의 지원을 하나의 결과로 묶지 않는다. X·Facebook 전경 경로는 사용자가 프로필을 열어 읽은 값을 위젯에 표시하는 구현이며, 앱을 열지 않아도 새 값을 수집하는 요구의 검증 성공을 뜻하지 않는다.

## 로그인에서 위젯까지

본인 계정의 로그인은 앱 안의 공식 SNS 페이지에서 사용자가 직접 진행한다. 비밀번호·쿠키·원시 명단은 채팅이나 저장소에 전달하지 않는다. 실기기 종류와 시험할 SNS가 정해지면 아래 순서로 결과를 기록한다.

1. OS·앱·WebView 버전, SNS 계정 유형과 익명 시험 식별자를 기록한다.
2. 공식 화면에서 자기 계정을 확인한 뒤 앱의 연결 확인을 실행한다. 정확한 수·수집 시각을 같은 시점의 공식 화면과 비교한다. 축약 수를 정확한 정수로 바꾸어 기록하지 않는다.
3. 연결 창을 닫고 앱에서 수 수집을 다시 실행한다. 다른 프로필, 로그인 만료, 확인 화면, 응답 변경이 마지막 정상 기록을 덮어쓰지 않는지도 확인한다.
4. 작은·중간·큰 홈 화면 위젯을 추가하고 표시 계정을 선택한다. 앱의 저장값·시각·상태와 비교하고 위젯을 눌러 앱이 열리는지 확인한다.
5. 앱을 열지 않은 상태에서 실제 새 수치가 관측되는지 확인한다. 예약 요청 시각, 실제 요청 시각, 위젯 표시 시각을 구분한다. 전경 수집 경로는 전경 전용으로 기록한다.
6. 앱 재실행·기기 재시작·화면 잠금·네트워크 단절과 복구·절전 상태를 검사한다. iOS에서는 서명된 앱·위젯의 App Group·Keychain 공유도 확인한다.
7. 대상 SNS 연결을 해제하고 그 SNS의 세션·기록만 제거되는지, 다른 SNS와 늦게 완료되는 요청에 영향이 없는지 확인한다.

## 관계 명단

Instagram 후보 경로에서 한 페이지를 넘는 명단을 읽고 정상 커서 종료·중복 제거·계정 일치·필터링 여부를 확인한다. 시작과 종료의 수가 같아도 동시점 스냅샷임을 증명하지는 않으므로 비원자적 수집으로 기록한다.

참여자가 동의한 시험 계정의 수동 관계 변경으로 맞팔의 두 방향, 첫 스캔 기준 생성, 이탈 후보, 다음 정상 스캔에서의 연속 미관측을 확인한다. 앱이 계정 삭제·비활성화와 실제 언팔로우 원인을 구분했다고 보고하지 않는다. 중간 페이지 실패와 취소 뒤에는 이전 완료 명단이 유지돼야 한다.

## 관찰 결과 양식

```text
시험 ID / OS / 앱 버전 / SNS / 계정 유형:
시험 시각 / 공식 화면 비교 시각:
로그인 및 자기 ID 확인:
정확한 수 수집과 정밀도:
WebView 종료 뒤 요청 결과 및 오류 종류:
전체 명단 페이지 수 / 종료 근거 / 불완전성:
작은·중간·큰 위젯 / 표시 계정 / 앱 열기:
예약 요청 / 실제 수집 / 위젯 갱신 시각:
잠금 / 재시작 / 단절 복구 / 절전:
연결 해제 후 세션·기록·다른 SNS 보존:
24시간 관찰 / 출시 후보 72시간 관찰:
확정할 기능 / 전경 전용 기능 / 실패·미검증 기능:
```

현재 실제 SNS 시험, 24시간 및 72시간 관찰 결과는 없다. 기간이 경과했다는 사실을 관찰 성공으로 대신 기록하지 않는다.
