# 팔로워 트래커 UI/UX

목표는 팔로워 수와 마지막 수집 시각을 빠르게 확인하고, 기능이 늘어나도 목적에 맞는 화면을 찾을 수 있게 하는 것이다. Android·iOS의 로그인·저장·수집·관계 비교 계약을 유지하며 화면과 탐색을 개선한다. 주요 목적지는 홈·관계·위젯·더보기로 통일하고 플랫폼에서 가능한 수집 동작과 위젯 추가 방법을 각각 안내한다.

## 탐색 구조

| 위치 | 주요 내용 |
| --- | --- |
| 홈 | 계정별 팔로워 수, 직전 기록 대비 변화, 수집 시각·상태, 계정 상세, Android 빠른 추적 시작·중지 |
| 관계 | 계정 선택, 맞팔 아님·언팔로우 추정·맞팔, 완료 명단의 비교 시각, 이름 검색과 검색어 지우기 |
| 위젯 | 작은/넓은 구성 미리보기, 계정 선택, Android 런처 추가 요청, iOS 홈 화면의 직접 추가 방법 |
| 더보기 | 연결된 계정, 수집 설정, 앱 지원, 도움말, 개인정보와 데이터 |

계정 상세에서는 최근 기록·최근 1시간·오늘을 선택할 수 있다. 선택한 기록 안의 첫 관측과 마지막 관측을 비교하고 시작·종료 시각을 함께 표시한다. 기록이 부족하면 변화 값을 만들어내지 않는다.

탭과 더보기 화면의 스크롤·검색·선택 상태를 보존한다. 도움말이나 개인정보 안내를 앱 지원 화면에서 열었다면 뒤로 가기는 앱 지원으로 돌아간다. 위젯을 누르면 반복 실행에서도 홈으로 이동한다. 연결 해제는 기존 확인창에서 삭제 범위를 알리고 실행한다.

iOS는 탭마다 NavigationStack을 사용하고 계정 상세는 홈의 하위 화면으로 연다. 지원 화면의 도움말·데이터 안내도 같은 더보기 경로를 사용한다. 선택 탭과 관계 검색·종류·방향, 위젯 미리보기 계정은 SceneStorage로 보존한다. SNS 선택과 공식 로그인은 큰 시트로 표시하고 로그인 완료 뒤 정확한 본인 수치를 확보하면 자동 연결한다.

## 시각과 접근성

밝은 회색 배경, 흰 표면, 파란 강조색과 차분한 녹색 변화 표시를 사용한다. 글자의 위계, 20dp/pt 바깥 여백, 카드·버튼의 모서리와 간격을 통일한다. 다크 모드는 시스템 설정을 따르며 실제 홈 위젯도 앱과 같은 색상 정의를 사용한다. iOS의 위젯 미리보기와 실제 확장은 같은 표시 컴포넌트를 사용한다.

Android의 주요 버튼은 최소 48dp 높이를 사용한다. 갱신 주기·기간 선택은 큰 글자와 좁은 화면에서 줄바꿈한다. 계정 선택에는 라디오 선택 의미를 제공하고, 아이콘 조작에는 설명을 붙인다. 주요 텍스트 색상 쌍의 대비와 320dp·글자 1.5배 화면은 런타임 검사 대상이다. 전체 TalkBack·접근성 준수를 확인한 것은 아니다.

iOS는 주 조작에 48pt 이상 높이를 사용하고 Dynamic Type으로 큰 숫자와 본문을 조절한다. 긴 기간·계정·관계 선택은 네이티브 메뉴를 사용한다. 좁은 화면의 버튼과 기록 행은 세로 배치로 바뀐다. VoiceOver에서 중복 읽는 장식 아이콘을 제외하고 검색어 지우기·새로고침·이전 페이지 조작에 이름을 제공한다. 실제 검사 범위와 전체 접근성의 미검증 항목은 구현 기록에 구분한다.

## 데이터와 상태

- 홈과 위젯은 수치와 실제 마지막 성공 시각을 함께 표시한다. 수집이 멈춘 뒤 상대 시간만 새 기록처럼 남지 않게 한다.
- 준비되지 않은 명단과 미지원 기능에 0이나 성공 결과를 표시하지 않는다. 빈 상태에서 다음 행동과 조건을 안내한다.
- Android의 빠른 추적은 Instagram을 대상으로 하며 알림·시간 제한·요청 제한을 유지한다. 자동 중지된 이유도 홈과 설정에 표시한다. 일반 명단을 매분 요청하는 기능으로 설명하지 않는다.
- Android 위젯 화면의 미리보기 선택은 추가 설정 화면의 기본값으로 전달한다. 실제 추가는 런처 확인창에서 계정을 확정한다. 크기는 홈 화면에서 조절한다.
- iOS 미리보기 선택은 앱 안에서 표시를 비교하는 선택이다. 실제 위젯의 계정은 홈 화면에서 위젯을 편집해 설정한다. 위젯은 마지막 성공 기록의 날짜·시각을 표시하며, iOS 1분 백그라운드 갱신을 보장하거나 빠른 추적 버튼을 제공하지 않는다.

## BM 화면

앞서 정한 유료 기능 없는 방향을 유지하며 `더보기 → 앱 지원`을 구성한다. 기본 기능 0원과 기능별 지원 조건을 보여주고, 광고·선택 후원 등의 운영 방식은 준비 상태로 명확히 표시한다. 가격·유료 구독·광고 SDK·실제 결제는 추가하지 않는다. 사용자 BM 방향이 확정되면 안내와 실제 제공 기능을 맞춰 갱신해야 한다.

앱 지원에서 도움말과 데이터 처리 안내로 이동할 수 있고, 도움말 질문은 펼치고 접을 수 있다. 준비되지 않은 결제 버튼이나 구매 완료 화면은 제공하지 않는다.

## 참고

[Android Navigation bar](https://developer.android.com/develop/ui/compose/components/navigation-bar)의 주요 목적지 탐색 패턴을 따른다. 경쟁 기능 구성은 [FollowMeter](https://play.google.com/store/apps/details?id=com.beakerapps.instameter2)와 [Followers & Unfollowers](https://play.google.com/store/apps/details?id=get.instagram.followers.unfollowers)의 현재 스토어 설명을 참고했다. 스토어 설명은 해당 앱의 실제 로그인·명단 정확도·사용성 우위를 검증한 자료가 아니다. 타사 코드·리소스를 복사하지 않았다.

실제 시험 결과와 범위는 [기기 검증](DEVICE_VALIDATION.md)과 [구현 기록](WORK_LOG.md)에 남긴다. iOS의 갱신 요청과 실제 실행 시각은 [Apple WidgetKit 갱신 안내](https://developer.apple.com/documentation/widgetkit/keeping-a-widget-up-to-date)에서 설명하는 시스템 실행·갱신 예산의 영향을 받는다.
