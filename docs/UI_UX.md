# 팔로워 트래커 UI/UX

목표는 팔로워 수와 마지막 수집 시각을 빠르게 확인하고, 기능이 늘어나도 목적에 맞는 화면을 찾을 수 있게 하는 것이다. Android·iOS의 로그인·저장·수집·관계 비교 계약을 유지하며 화면과 탐색을 개선한다. 주요 목적지는 계정·분석·위젯·설정으로 통일하고 플랫폼에서 가능한 수집 동작과 위젯 추가 방법을 각각 안내한다.

## SNS 로고와 계정 카드

SNS 선택·로그인·계정·관계 분석·계정관리 화면의 `IG`·`Tk`·`f` 등 문자 표기를 공식 브랜드 자료의 벡터 로고로 교체했다. [에셋 출처](../shared/brand-assets/README.md)와 해시를 보관하고 로고에 임의의 색을 덧씌우지 않는다. Android는 네이티브 VectorDrawable, iOS는 벡터 보존 SVG 에셋을 사용해 화면 표시를 위한 네트워크 요청과 WebView를 추가하지 않는다.

계정 탭과 계정관리의 연결된 계정 카드는 로고 외에도 카드 전체의 은은한 그라데이션, 상단 색 띠, 테두리와 액션·그래프 색상으로 플랫폼을 구분한다. Instagram은 보라·분홍·주황, TikTok은 청록·분홍, X는 흑백, Facebook은 파랑, Reddit은 주황이다. 밝은/어두운 테마의 본문·보조 문구·액션 대비는 4.5:1 이상을 기준으로 한다. 플랫폼 이름과 상태 안내를 유지해 색상만으로 의미를 전달하지 않는다. Facebook 개인 프로필과 페이지에는 같은 브랜드 색을 쓰고 기존 제목·연결 동작으로 유형을 구별한다.

`ProviderBrandRuntimeTest`는 계정·세션·수집 설정을 읽거나 쓰지 않는 합성 화면으로 다섯 로고의 실제 렌더링과 두 테마의 글자 대비를 검사한다. 사용자 세션이 있는 기기에서도 이 클래스만 선택 실행할 수 있다. 전체 instrumentation 묶음은 기존 지침대로 별도 QA 기기에만 실행한다.

## 탐색 구조

| 위치 | 주요 내용 |
| --- | --- |
| 계정 | 연결된 SNS별 팔로워 수, 직전 기록 대비 변화, 변화 그래프, 수집 시각·상태, 계정 상세와 새로고침 |
| 분석 | 계정 선택, 맞팔 아님·언팔로우 추정·맞팔, 완료 명단의 비교 시각, 이름 검색과 검색어 지우기 |
| 위젯 | 작은/넓은 구성 미리보기, 계정 선택, Android 런처 추가 요청, iOS 홈 화면의 직접 추가 방법 |
| 설정 | 연결 관리, Android 빠른 추적 시작·중지와 상태, 수집 안내, 앱 지원, 도움말, 개인정보와 데이터 |

계정 화면은 연결된 SNS의 기록에 집중한다. 빠른 추적 카드, 위젯 추가 안내, 무료 기능·데이터 보관 홍보 문구는 계정 화면에서 제외한다. 연결 전에는 계정 연결 행동을, 연결 후에는 SNS별 기록 카드를 보여준다. 빠른 추적은 `설정 → 수집 설정`에서 조작하고 위젯 안내는 위젯 탭에서 확인한다.

일반 수집 요청은 15분 간격으로 고정하고 Android·iOS 설정의 간격 선택 카드·메뉴를 제거한다. 사용자가 빠른 추적을 시작하지 않거나 중지해도 일반 예약은 유지한다. Android의 이전 30분·60분·2시간 예약은 앱 시작 시 같은 작업을 갱신하며, iOS 앱·위젯은 이전 저장값을 사용하지 않는다. 도움말에서 기본 간격과 운영체제·네트워크·SNS 요청 제한에 따른 지연을 안내한다.

계정 카드의 `팔로워` 제목 오른쪽에 실제 마지막 성공 수집 시각을 기준으로 `갱신 0분 전`을 표시한다. 화면이 보이는 동안 경과 시간을 주기적으로 다시 계산하며, 수집 기록이 없으면 `수집 대기`를 표시한다. 정상 카드 하단의 상태·날짜 두 줄과 구분선은 제거한다. 로그인 문제·요청 제한 등의 상태는 계정 이름 아래에 표시하고, 정확한 수집 날짜와 시각은 계정 상세에서 확인한다.

계정 상세에서는 최근 기록·최근 1시간·오늘을 선택할 수 있다. 선택한 기록 안의 첫 관측과 마지막 관측을 비교하고 시작·종료 시각을 함께 표시한다. 기록이 부족하면 변화 값을 만들어내지 않는다.

2026-10-21에는 Android·iOS 계정 상세의 `로그아웃`을 계정 이름 오른쪽으로 옮겼다. 상세 화면을 열자마자 스크롤 없이 접근하며, 실행 전 확인창에서 해당 SNS의 로그인만 제거하고 기존 기록을 유지하는 범위를 안내한다. Android 실기기에서 상단 버튼 표시·확인창·로그아웃 뒤 기존 계정과 수집 기록 보존을 확인했다. iOS는 빌드를 검증했으며 실제 화면은 미실행이다.

2026-10-22에는 로그아웃 뒤 카드가 남는 동작을 변경했다. 명시적으로 로그아웃한 계정은 연결 목록·분석 선택·위젯에서 빠진다. 이력은 보관하고 같은 계정으로 새 로그인에 성공하면 복원하며, 다른 계정과 합치지 않는다. 인증이 만료된 연결은 계속 재로그인 안내를 보여준다. 확인창과 연결 관리 설명에 이 차이를 반영한다.

탭과 설정 화면의 스크롤·검색·선택 상태를 보존한다. 도움말이나 개인정보 안내를 앱 지원 화면에서 열었다면 뒤로 가기는 앱 지원으로 돌아간다. 위젯을 누르면 반복 실행에서도 계정 탭으로 이동한다. 연결 해제는 기존 확인창에서 삭제 범위를 알리고 실행한다.

iOS는 탭마다 NavigationStack을 사용하고 계정 상세는 계정 탭의 하위 화면으로 연다. 지원 화면의 도움말·데이터 안내도 같은 설정 경로를 사용한다. 선택 탭과 관계 검색·종류·방향, 위젯 미리보기 계정은 SceneStorage로 보존한다. 표시 이름을 바꿔도 기존 탭 식별자와 위젯 진입 계약을 유지한다. SNS 선택과 공식 로그인은 큰 시트로 표시하고 로그인 완료 뒤 정확한 본인 수치를 확보하면 자동 연결한다.

Facebook 페이지는 링크 입력란 옆의 `연결` 버튼과 키보드의 이동 조작을 사용한다. 로그인 전에도 링크를 제출할 수 있고 인증 완료 뒤 그 페이지를 새로 열어 자동으로 확인한다. 일반 페이지 링크에는 추가 확인 조작이 없으며, 공유 링크와 직접 탐색에는 화면 아래 `이 페이지 연결`을 사용한다. 로그인·페이지 열기·수치 확인·공유 대상 확인을 안내 문구로 구별하고, 개인 프로필이나 다른 페이지를 잘못 저장하지 않는다. [자세한 연결 흐름](FACEBOOK_PAGES.md)

## 시각과 접근성

밝은 회색 배경, 흰 표면, 파란 강조색과 차분한 녹색 변화 표시를 사용한다. 글자의 위계, 20dp/pt 바깥 여백, 카드·버튼의 모서리와 간격을 통일한다. 다크 모드는 시스템 설정을 따르며 실제 홈 위젯도 앱과 같은 색상 정의를 사용한다. iOS의 위젯 미리보기와 실제 확장은 같은 표시 컴포넌트를 사용한다.

Android의 주요 버튼은 최소 48dp 높이를 사용한다. 기간 선택은 큰 글자와 좁은 화면에서 줄바꿈한다. 계정 선택에는 라디오 선택 의미를 제공하고, 아이콘 조작에는 설명을 붙인다. 주요 텍스트 색상 쌍의 대비와 320dp·글자 1.5배 화면은 런타임 검사 대상이다. 전체 TalkBack·접근성 준수를 확인한 것은 아니다.

위젯은 **내 계정**과 **소셜 모아보기** 두 종류다. Android 내 계정은 1×1 격자를 기본으로 SNS 하나의 공식 로고·브랜드 그라데이션·팔로워 수·마지막 실제 수집 시각을 표시한다. 공간을 늘리면 계정명·증감·비교 기준 시각도 표시한다. 좁은 칸에서 긴 숫자는 만·억·조·경 단위로 축약하며 저장값과 접근성 설명은 정확한 수를 유지한다. 소셜 모아보기는 기본 4×4 대형으로 연결된 모든 계정의 색상별 행을 표시한다. 높이가 부족하거나 계정이 많으면 안정적인 계정 ID를 가진 스크롤 목록으로 전환해 세 개·다섯 개 제한 없이 전부 접근할 수 있다. 실제 칸 크기와 여백은 런처가 결정한다. [두 위젯의 크기·호환성·검증](WIDGET_DESIGN.md)

iOS는 주 조작에 48pt 이상 높이를 사용하고 Dynamic Type으로 큰 숫자와 본문을 조절한다. 긴 기간·계정·관계 선택은 네이티브 메뉴를 사용한다. 좁은 화면의 버튼과 기록 행은 세로 배치로 바뀐다. VoiceOver에서 중복 읽는 장식 아이콘을 제외하고 검색어 지우기·새로고침·이전 페이지 조작에 이름을 제공한다. 실제 검사 범위와 전체 접근성의 미검증 항목은 구현 기록에 구분한다.

## 데이터와 상태

- 계정과 위젯은 수치와 실제 마지막 성공 시각을 함께 표시한다. 수집이 멈춘 뒤 상대 시간만 새 기록처럼 남지 않게 한다.
- 네트워크 단절과 일시적인 서버 오류는 `일시 오류`로 표시하고 마지막 정상 수치·비교·수집 시각을 유지한다. 오류 시각을 새 수집 시각으로 표시하지 않는다. 자동 재시도는 대기 후 진행하며, 로그인 문제에는 별도로 `다시 로그인 필요`를 표시한다.
- 준비되지 않은 명단과 미지원 기능에 0이나 성공 결과를 표시하지 않는다. 빈 상태에서 다음 행동과 조건을 안내한다.
- Android의 빠른 추적은 연결된 SNS 개인 프로필의 수를 대상으로 하며 알림·시간 제한·요청 제한을 유지한다. 확인이 필요한 SNS는 마지막 정상값을 유지하고 가능한 계정의 추적은 계속한다. Facebook 페이지는 페이지를 열고 확인하는 별도 흐름을 유지한다. 자동 중지된 이유는 수집 설정에 표시하고, 앱 프로세스를 다시 시작해도 중지 사유와 마지막 성공 수집 시각을 유지한다. 실행 중 프로세스가 종료됐다면 중단 상태를 표시한다. 프리미엄 시험의 실행 요청이 남아 있으면 앱 재진입 때 복구를 시도하고, 인증 만료 상태에서는 연결을 기다린다. 일반 빠른 추적은 직접 다시 시작한다. 일반 명단을 매분 요청하는 기능으로 설명하지 않는다.
- Android 앱을 강제 중지하면 빠른 추적과 일반 예약이 멈춘다. Android 15 이상에서는 OS가 홈 위젯도 회색으로 비활성화하므로, 도움말의 `위젯이 회색으로 바뀌었어요`와 위젯 탭에서 앱 아이콘으로 다시 여는 방법을 안내한다. 일반 빠른 추적은 사용자가 다시 시작하고, 프리미엄 시험은 앱 재진입 뒤 남은 요청으로 복구를 시도한다. [Android 강제 중지와 위젯](https://developer.android.com/about/versions/15/behavior-changes-all?hl=en)
- Android 위젯 화면은 내 계정·모아보기 두 선택과 실제 Glance RemoteViews 미리보기를 사용한다. 내 계정의 선택은 pin callback에서 위젯별로 저장하고, 재구성 시 해당 위젯의 저장값을 먼저 읽는다. 모아보기는 계정 선택 없이 새 연결까지 자동 포함한다. 크기는 홈 화면에서 조절한다.
- iOS는 내 계정 `systemSmall`과 소셜 모아보기 `systemLarge` 두 종류를 등록한다. 앱의 계정 선택은 소형 미리보기에만 적용하며 대형은 모든 개인 계정을 표시한다. 실제 소형 위젯의 SNS는 홈 화면에서 위젯을 편집해 설정한다. 위젯은 마지막 성공 기록의 날짜·시각을 표시하며, iOS 1분 백그라운드 갱신을 보장하거나 빠른 추적 버튼을 제공하지 않는다.

## BM 화면

앞서 정한 유료 기능 없는 방향을 유지하며 `설정 → 앱 지원`을 구성한다. 기본 기능 0원과 기능별 지원 조건을 보여주고, 광고·선택 후원 등의 운영 방식은 준비 상태로 명확히 표시한다. 가격·유료 구독·광고 SDK·실제 결제는 추가하지 않는다. 사용자 BM 방향이 확정되면 안내와 실제 제공 기능을 맞춰 갱신해야 한다.

앱 지원에서 도움말과 데이터 처리 안내로 이동할 수 있고, 도움말 질문은 펼치고 접을 수 있다. 준비되지 않은 결제 버튼이나 구매 완료 화면은 제공하지 않는다.

## 참고

[Android Navigation bar](https://developer.android.com/develop/ui/compose/components/navigation-bar)의 주요 목적지 탐색 패턴을 따른다. 경쟁 기능 구성은 [FollowMeter](https://play.google.com/store/apps/details?id=com.beakerapps.instameter2)와 [Followers & Unfollowers](https://play.google.com/store/apps/details?id=get.instagram.followers.unfollowers)의 현재 스토어 설명을 참고했다. 스토어 설명은 해당 앱의 실제 로그인·명단 정확도·사용성 우위를 검증한 자료가 아니다. 타사 코드·리소스를 복사하지 않았다.

실제 시험 결과와 범위는 [기기 검증](DEVICE_VALIDATION.md)과 [구현 기록](WORK_LOG.md)에 남긴다. iOS의 갱신 요청과 실제 실행 시각은 [Apple WidgetKit 갱신 안내](https://developer.apple.com/documentation/widgetkit/keeping-a-widget-up-to-date)에서 설명하는 시스템 실행·갱신 예산의 영향을 받는다.

2026-10-19에는 계정 상세·연결 관리에 기록을 남기는 로그아웃을 추가했다. 소형 위젯은 여백·로고를 줄이고 팔로잉 또는 실제 이전 팔로워 수를 표시하며, 위젯 탭의 큰 표어·중복 설명을 제거했다. [복구·로그아웃·소형 표시 검증](CONTINUITY_AND_LOGOUT.md)
